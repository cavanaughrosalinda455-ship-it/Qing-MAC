# 清清 Mac

原生 SwiftUI macOS 清理工具原型。支持 macOS 14 或更新版本。清理前会展示所选文件并要求确认。

## 构建与运行

安装 Xcode 或 Command Line Tools 后，在项目目录运行 `zsh build.sh`。脚本使用当前 Mac 的架构，将应用构建到 `outputs/清清 Mac.app`；也可通过 `TARGET_ARCH=arm64` 或 `TARGET_ARCH=x86_64` 指定目标架构。脚本优先使用已验证的 macOS 26.5 SDK（若已安装），否则使用 `xcrun` 的当前 SDK；编译器与 SDK 不兼容时可通过 `SDK_PATH` 指定。项目保留 `Package.swift`，脚本直接调用 `swiftc`。若 `Resources/AppIcon.icns` 未提供，构建出的应用使用系统默认图标。

本地构建使用临时签名，未经过 Apple 公证。首次运行时 macOS 可能要求在“系统设置 → 隐私与安全性”中确认打开。部分清理目录需要“完全磁盘访问”。

## 当前功能

- **清理**：智能扫描、27 类系统垃圾扫描、Apple Mail 附件及 Outlook/Spark 邮件缓存、当前用户和已挂载外置卷的废纸篓。可取消扫描、查看进度和无法读取的路径。普通扫描结果默认全选，清理前逐项核对并再次确认；iOS 备份为了防止误删，默认不选中。此前截图所在的 `codex-clipboard-*.png` 临时目录也会扫描，最近 15 分钟的截图暂时跳过。
- **防护**：读取当前用户 TCC 授权记录；查看和忘记已保存的 Wi-Fi；查看 XProtect 状态。若自行安装 ClamAV，可扫描指定目录并逐项处理匹配文件。浏览器隐私页列出 Safari、Chrome、Edge、Firefox 的历史记录或 Cookie 文件，清理前请退出浏览器。
- **性能**：查看并启停当前用户的传统 LaunchAgent；重置 Quick Look 缓存、刷新 DNS 缓存、查看 Spotlight 状态。
- **应用**：查找应用及其常见用户库关联文件，逐项选择卸载或重置；查看传统插件、面板及 Safari 扩展；进入系统更新界面。
- **文件**：可点击深入的目录空间图；查找 50 MB 以上大文件和一年未修改的旧文件；逐级哈希验证重复文件并保留一个原件，将所选副本移到废纸篓；可选择文件永久删除。
- **菜单栏**：沿用现有紧凑外观；通过原生 64 位网卡计数器每秒计算网络接收和发送速度，以 MB/s 显示，无需反复启动 `netstat`。其余 CPU、内存、磁盘、电池、运行时间、交换空间简述及建议每 15 秒刷新。首次网络采样显示“测量中”。

## 当前边界

- 智能扫描会汇总清理项目，并只读检查防护与性能状态；恶意软件扫描和维护操作仍需到各自页面执行。浏览器隐私清理按文件进行，尚无按时间范围筛选。
- ClamAV 需要单独安装并维护签名库；检测并非完整杀毒保证，可能误报。未安装时应用不会声称已完成恶意软件扫描。
- 重复文件目前支持确认后移走副本，尚未实现 APFS 克隆合并。文件永久删除不等同于 SSD/APFS 上可保证的安全擦除。
- 通用二进制减薄、Sparkle 更新源检查、系统级维护批处理及高级菜单栏传感器尚未实现。重写已签名应用的 Mach-O 文件会破坏签名，因此不会自动这样做。
- TCC 数据库和部分缓存目录可能需要“完全磁盘访问”才能读取；应用会列出扫描失败的路径。系统权限开关仍由 macOS 系统设置管理。
